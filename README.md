# wuhu · 一封会动的情书 💌

一个动态、可交互的表白网页 —— 男 INFP 天秤 写给 女 ENFP 双子。

纯静态页面（HTML + CSS + 原生 JS），无需任何构建工具或依赖。

## 直接打开

双击 `index.html`，或用浏览器打开即可。

## 本地预览（可选）

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 体验流程

1. 💌 **打开信封** —— 点击信封，背景轻柔旋律响起
2. ⌨️ **开场白** —— 逐字打字机效果
3. 💞 **灵魂配对报告** —— INFP 天秤 × ENFP 双子，契合度进度条
4. 🃏 **喜欢你的理由** —— 可翻转的卡片
5. ☀️ **大问题** —— "你愿意吗？"（"再想想"按钮会调皮地躲开）
6. 🎉 **庆祝** —— 爱心彩纸喷发 + 甜甜的结语

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构与全部文案 |
| `style.css` | 样式、布局与动画 |
| `script.js` | 交互逻辑、粒子背景、Web Audio 旋律 |

> 背景音乐由 Web Audio 程序实时生成，不依赖外部音频文件。
