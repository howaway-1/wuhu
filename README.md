# wuhu · 致最特别的你 💌

一个仿苹果官网风格的表白长页面 —— 男 INFP 天秤 写给 女 ENFP 双子。

纯静态页面（HTML + CSS + 原生 JS），无构建工具、无依赖。设计借鉴 Apple
产品发布页：大量留白、超大粗体标题、磨砂玻璃导航、苹果蓝胶囊按钮、滚动淡入叙事。

## 直接打开

双击 `index.html`，或用浏览器打开即可。

## 本地预览（可选）

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 页面结构（自上而下滚动）

1. **导航** —— 顶部磨砂玻璃固定栏
2. **Hero** —— 超大标题「你，是我见过最亮的光。」+ 苹果蓝按钮
3. **大字陈述** —— 黑底沉浸式段落，滚动淡入
4. **灵魂配对** —— 天秤 ♎ × 双子 ♊ 规格卡片 + 超大「99%」契合度数字（滚动到位时跳动）
5. **喜欢你的理由** —— bento 卡片网格（悬停上浮）
6. **表白** —— 黑底高潮，「我愿意」胶囊按钮 +「再想想」会躲开的按钮
7. **庆祝** —— 点「我愿意」后全屏彩纸 + 爱心 + 结语

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构与全部文案 |
| `style.css` | Apple 风格样式、布局、动画 |
| `script.js` | 滚动淡入、数字跳动、躲避按钮、彩纸庆祝 |
